Peekdown

Preview Markdown documents and thumbnails in Finder.

Choose where to install on the Destination Select screen, or use Change Install Location… on the Installation Type screen:

  • Install for me only: installs in your home folder’s Applications folder. No administrator password is needed.
  • Install for all users of this computer: installs in the shared Applications folder and requires administrator authorization.

After installation, open Peekdown from the Applications folder you selected. Enable its Quick Look extensions in System Settings if prompted.

When switching between a personal and shared installation, remove the previous copy to avoid duplicate Quick Look extensions. Removing a shared installation may require administrator access.
