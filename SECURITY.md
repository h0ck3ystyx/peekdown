# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it through GitHub's private vulnerability reporting feature:

1. Navigate to the [Security tab](../../security)
2. Click "Report a vulnerability"
3. Fill out the vulnerability report form with as much detail as possible

We take all security reports seriously and will respond as quickly as possible. Please do not disclose the vulnerability publicly until we have had a chance to address it.

Thank you for helping keep this project and its users safe!
