What renders

Readable Markdown, one keystroke away.

Peekdown renders common Markdown and selected GitHub-style features with a dependency-free Swift renderer and native AppKit text.

Markdown essentials

Headings, tables, task lists, strikethrough, links and blockquotes. Read your README without opening an editor.

Readable code blocks

Fenced and indented code blocks use monospaced text. Inline code stands out within paragraphs, without a browser or JavaScript.

Finder thumbnails

See a document’s first heading and a short text snippet in a styled Markdown thumbnail, alongside the full Quick Look preview.

Matches your Mac

Follows Light and Dark appearance using native system text colors, with system fonts for prose and monospaced fonts for code.

Private by design

The native app runs in Apple’s App Sandbox without network access. Images appear as alt text; remote images are not downloaded.

Front matter aware

YAML front matter at the start of a document is hidden so the preview begins with your Markdown content.

Install

Choose how to install.

  1. Install the app

    Homebrew (recommended): Run this command. The Quick Look extensions register automatically on install.

    brew install --cask h0ck3ystyx/tap/peekdown

    Manual install: Download the signed, notarized installer. Choose Install for me only for ~/Applications without admin access, or Install for all users for /Applications with admin authorization. If needed, click Change Install Location…. Prefer a ZIP? Extract the ZIP and move the app to ~/Applications. Create that folder if needed.

  2. Open it once

    If you used the installer or ZIP, open Peekdown from the Applications folder so macOS can discover its extensions. You can quit it afterward. Homebrew installs handle this automatically.

  3. Turn on the extension

    If previews do not appear, look for Quick Look in System Settings. On recent macOS versions, go to

    General › Login Items & Extensions › Quick Look

    and switch on Peekdown.

  4. Press space on any .md file

    Select a Markdown file in Finder and tap the space bar.

Homebrew commands

Update to the latest release or remove Peekdown.

# upgrade to the latest version
brew upgrade --cask peekdown

# uninstall
brew uninstall --cask peekdown

Preview not showing?

Reset the Quick Look cache, then select a Markdown file in Finder and press Space. Avoid keeping both Peekdown and the old MarkdownPreview app installed.

# clear cached generators and thumbnails
qlmanage -r && qlmanage -r cache
